# QuantResearch

Eigenständige quantitative Finanzmarktforschung.

## Grundsätze
- Wissenschaftliche Hypothesen vor Messungen festlegen
- Datenqualität und Informationsverfügbarkeit prüfen
- Chronologische Out-of-sample-Validierung
- Negative Ergebnisse vollständig dokumentieren
- Explorative Ergebnisse nicht als bestätigt bezeichnen
- Keine Strategieentwicklung oder Orderausführung
- Keine Änderungen an TradingLab oder Paper-Bots

## Historischer Bestand
R1 bis R3: Frühere explorative Studien.
R4: BTC -> ETH Rendite, explorativ negativ.
R5: BTC -> ETH Volatilität, explorativ positiv,
    technisch reproduziert.
R6: BTC -> SOL Volatilität, explorativ positiv,
    technisch und statistisch reproduziert.

Historische Berichte sind keine nachträglichen
Vorregistrierungen. Die unabhängige Validierung
von R5 und R6 steht noch aus.
